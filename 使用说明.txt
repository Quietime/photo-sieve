照片快筛 · 原生 Windows 桌面版 3.3.0

1. 双击 PhotoSieve-Setup-Windows-x64.exe，选择安装位置。安装后从桌面快捷方式启动。
   无需浏览器、无需安装 Python。请保留 _internal 文件夹。
2. 点击“打开文件夹…”，或把照片文件夹直接拖进窗口，会自动扫描（包括子文件夹）。
   每次启动先选择文件夹。关闭可保存或重置浏览位置，照片和筛选记录仍保留。
3. 两张连续照片并排显示，所有筛选操作针对左图：
   ↑ 保留；↓ 删除；→ 或在图片上右键：下一张；← 恢复最近删除；Ctrl+Z 撤回最近一次操作。
   按住 ↑ / ↓ / → 可以连续快速筛选，按键后立即显示下一张，记录在后台写入。
   左图预览还没读出来时不会被筛选，图片会轻轻晃一下提示稍等。
   这些按键都可以在右上角“⋯”→“快捷键…”里改，每个操作可设两个键，也可以全部留空。
4. 顶部的“未筛选 / 保留 / 已删除”切换视图，数字是各自的数量。
   保留的照片不再出现在未筛选和下方缩略图里。
5. 单击任一图片，或按 Z，在原位平滑放大到 100%。
   新款索尼等相机的 RAW 直接显示相机内嵌的全尺寸 JPG，不到半秒；老机型从 RAW 数据完整解码。
   放大后滚轮以鼠标位置为中心缩放（向上放大、向下缩小），范围为适应窗口到 800%。
   拖动查看细节；再点一次或按 Esc 还原。
6. ↓ 会把照片移到该照片原文件夹下的 .photo-sieve-trash。
   这不是 Windows 回收站，仍占用空间，不会自动永久清除。
   在“已删除”里双击照片，或选中后点“恢复所选”，即可放回原位置。
7. 筛选完成后点右上角“导出”，选择目标文件夹：
   复制：原片保留在原处；移动：原片转到目标文件夹，不能用 ← 撤回。
   保持原文件名和子文件夹，目标中已有的同名文件会跳过，不会覆盖。
8. 默认沿用 %USERPROFILE%\.photo-sieve 中的筛选记录。
   请保留这个目录和 .photo-sieve-trash，重启后仍可恢复。
9. 右上角“⋯”菜单底部显示本机配置：核数、内存、解码进程数、预读张数和合成方式。
   “GPU 合成”默认开启，重启后生效；“显示帧率”可以查看画面每秒实际刷新几次。
10. 关闭窗口时，如果还有刚按下的筛选记录在写入，APP 会提示并在写完后自动关闭。
   扫描或导出进行中时请等待完成。

适用 Windows 10 / 11 64 位。更多说明和性能数据请查看 README.md。
若下载的是源码包：start_windows.bat 安装依赖后运行桌面界面；
build_windows.bat 用于在 Windows 上生成 EXE。

自动更新：从 GitHub 公开仓库获取新版，无需登录。发现新版本时会弹出提示，
点“下载并更新”后在后台下载，下载时可以继续筛选；下载完成并停止操作 3 秒后自动安装、重启，
装好后自动删除下载的安装包和旧版备份。照片、筛选记录、删除暂存文件和设置都会保留。
点“以后再说”则下次启动再提示。可以在“⋯”菜单关闭“启动时检查更新”，或随时手动“检查更新”。

3.2：动作图标固定，快捷键单独显示在标签中，备用键可悬停查看。
“⋯”菜单可减少动态、减少透明效果；默认尊重 Windows 系统偏好。
Tab / Shift+Tab 可移动键盘焦点，空格激活按钮；聚焦顶部分类后用左右键或 Home / End 切换视图。

3.3 新功能：内置窗口按钮和应用图标；左右照片居中并注明角色；已删除页可全选和确认后彻底删除。
照片留在原处，只扫描照片格式，忽略音频和视频。缓存和记录存入安装目录 workspaces。
“⋯”→“预加载与缓存”可调整预加载数量和清理缓存。每分钟自动清理已筛选照片的旧预览，保留两分钟供快速撤回。总预览缓存超过 10 GB 时，从最老的开始在一轮内清理到限额内。
