照片快筛 · 原生 Windows 桌面版 v2

1. 解压整个 APP 压缩包，双击 PhotoSieve.exe。
   无需浏览器、无需安装 Python。请保留 _internal 文件夹。
2. 每次启动时路径输入框为空，原照片和筛选记录照常保留。
   选择照片文件夹，点击“扫描 / 更新目录”，等待扫描结束。
3. 两张连续照片并排显示，所有筛选操作针对左图：
   ↑ 保留；↓ 删除；→ 或图片右键下一张；← 恢复最近删除。
   Ctrl+Z 撤回最近一次操作。“上一张”按钮用于回看。
4. 默认“未筛选”队列不再显示保留照片，下方列表也不显示保留照片。
   在左侧“保留”页面可查看所有已保留照片。
5. 单击任一图片，直接在当前位置放大，不新开窗口。
   再点一次或按 Esc 恢复双图；拖动或滚动条移动查看细节。
   先立即放大预览，再在后台读取原始像素；RAW 可能需要等几秒。
   底部所有列出的照片均加载缩略图，不再只显示前 6 张。
6. ↓ 会将照片移到该照片原目录下的 .photo-sieve-trash。
   这不是 Windows 回收站，仍占用空间，不会自动永久清除。
   “已删除 · 可恢复”中显示原路径和实际暂存路径，支持单独恢复。
7. 筛选完成点击“复制 / 移动保留照片…”，选择新文件夹：
   复制保留原片；移动会转移原片，不能用 ← 撤回移动。
   保存全部保留照片，保持原文件名和子目录，不覆盖目标同名文件。
   完成后再次打开窗口查看结果、失败原因或打开输出目录。
8. 关闭旧版 Python 后台后再用本版。默认沿用旧版筛选记录：
   %USERPROFILE%\.photo-sieve
   请保留这个目录和 .photo-sieve-trash，重启后仍可恢复。
   旧版自定义资料库需使用同一个 --data-dir 参数。
9. 请等待扫描、复制、移动或删除操作完成后关闭 APP。

适用 Windows 10 / 11 64 位。更多说明和限制请查看 README.md。
若下载的是源码包：start_windows.bat 安装依赖后运行桌面界面；
build_windows.bat 用于在 Windows 上生成 EXE。

自动更新：先手动安装 3.0.0，然后在 APP 的“GitHub 更新设置”填写只有仓库 Contents 读取权限的 GitHub 细粒度令牌。令牌保存到 Windows 凭据管理器。更新会保留照片、筛选记录和删除暂存文件；停止操作 30 秒后安装重启。可关闭自动安装，仍可手动检查更新。
